# PokeDecompose 1.1.1 安装与配置说明

## 新增功能

六类精灵分别显示 GUI 奖励说明：

- 普通精灵：`GuiReward.normal`
- 普通闪光：`GuiReward.shiny`
- 神兽/异兽：`GuiReward.legendary`
- 闪光神兽/异兽：`GuiReward.shiny_legendary`
- 幻兽：`GuiReward.mythical`
- 闪光幻兽：`GuiReward.shiny_mythical`

默认示例中，普通显示 `200 金币`，普通闪光显示 `5 个分解石`。

`GuiReward` 只控制 GUI 和成功提示文字，不负责实际发奖。实际奖励仍由对应的六个 Command 列表执行，请确保两者一致。

## GUI 占位符

- `%价格%`、`%price%`：在 GUI 中显示当前分类奖励说明。
- `%奖励%`、`%reward%`：当前分类奖励说明。
- `%计算价格%`、`%calculated_price%`：原价格公式计算值。

命令列表中的 `%price%` 仍是原价格数值，没有改变。

## 安装

1. 完整关闭服务器。
2. 删除旧版 PokeDecompose JAR。
3. 放入 1.1.1 JAR。
4. 备份并删除旧 `plugins/PokeDecompose/config.yml`，让插件释放完整新配置；或手动合并 `GuiReward` 段落。
5. 修改六个命令区，使实际奖励与 GUI 提示一致。
6. 完整启动服务器测试。
