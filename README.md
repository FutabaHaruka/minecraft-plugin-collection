# Minecraft Plugin Collection

这是一次将历史生成/修复的 Minecraft 插件、Forge Mod 与补丁源码统一整理后的 GitHub 源码集合。

## 目录

- `projects/`：相对完整、适合作为源码项目继续维护的项目。
- `patch-projects/`：基于既有插件/JAR 修复、局部重构或只有局部源码的项目。公开前应确认原项目许可证与再分发权限。
- `pixelmon-patches/`：Pixelmon 相关补丁源码/构建脚本。**不包含 Pixelmon 完整 JAR**。
- `PROJECT_INDEX.md`：项目清单、版本和可发布状态。
- `UPLOAD_GUIDE.md`：GitHub 上传步骤。
- `PUBLICATION_CHECKLIST.md`：公开仓库前检查事项。

> 注意：本仓库包刻意不放最终 JAR。可运行 JAR 被整理到单独的 `Minecraft-Plugins-Release-Assets-LOCAL-ONLY.zip` 中，是否上传 GitHub Release 请按许可证逐项判断。
